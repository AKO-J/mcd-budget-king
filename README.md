# 穷鬼点单王

预算约束下的麦当劳最优点餐 Skill。输入预算，输出在预算内"最划算"的点餐组合——不是让大模型拍脑袋推荐，而是用组合优化算法精确求解。

## 主要功能

- **吃饱模式**：给定预算，在预算内选择饱腹度总分最高的商品组合（0-1 背包，动态规划精确求解）
- **省钱模式**：给定必选品类及数量（如 1 个汉堡 + 1 杯饮料），选择总价最低的组合
- 菜单优先从麦当劳 MCP（`https://mcp.mcd.cn`）实时获取，失败时回退本地示例菜单

## 安装方法

1. 安装 Python 3.10 或更高版本
2. （可选）如需实时菜单，安装 MCP 客户端并配置 Token：

```bash
pip install mcp httpx
export MCD_MCP_TOKEN=你的麦当劳MCP_Token  # 从 https://open.mcd.cn/mcp 控制台获取
```

## 使用示例

```bash
# 吃饱模式：30 元预算，饱腹度拉满
python main.py --budget 30 --mode 吃饱

# 省钱模式：必须含 1 个汉堡 + 1 杯饮料，总价最低
python main.py --budget 50 --mode 省钱 --need "汉堡:1,饮料:1"

# 使用 MCP 实时菜单（需先 export MCD_MCP_TOKEN）
# 会按城市自动找一家到店自取门店，拉取该店实时餐品与现价
python main.py --budget 30 --mode 吃饱 --mcp
```

输出示例：

```text
[吃饱模式] 预算 30.0 元（数据来源：本地示例菜单）
推荐组合：
  - 大薯条 x1  18.50 元  饱腹度 8
  - 香芋派 x1  8.50 元  饱腹度 4
总价：27.00 元，剩余预算：3.00 元
总饱腹度：12（启发式评分，仅供参考）
```

## 目标用户

预算有限但想吃得划算的麦当劳消费者，以及对"AI + 组合优化"感兴趣的开发者。

## 注意事项

- 本项目为麦当劳程序员创意开发大赛参赛作品，非麦当劳官方产品
- 本地 `menu.json` 为示例菜单数据，仅用于离线演示；实际餐品、价格与供应情况以麦当劳 MCP 返回的实时数据为准
- 饱腹度评分为启发式指标，不代表真实营养价值，不构成营养建议
- 请勿将真实 Token 提交到仓库，统一使用环境变量 `MCD_MCP_TOKEN`
